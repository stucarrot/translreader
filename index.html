      번역 설정

      API 키는 이 브라우저의 로컬 저장소에만 저장됩니다 (다른 서버로 전송되지 않음). 새로고침해도 유지되며, 원치 않으면 아래 "키 지우기"로 즉시 삭제할 수 있습니다.
      첫 번째 키가 실패(할당량 초과·오류)하면 다음 키로 자동 전환됩니다. 모든 키가 실패하면 구글 번역으로 자동 대체됩니다. 키를 하나도 입력하지 않으면 처음부터 구글 번역만 사용합니다.
      {lang}는 번역 대상 언어로, {text}는 원문 조각으로 자동 치환됩니다. 대사 개행 방식, 존댓말/반말, 용어 통일 규칙 등을 자유롭게 수정하세요. (구글 번역 폴백에는 적용되지 않고 Gemini 호출에만 적용됩니다.)
      GitHub Pages는 정적 사이트라 서버가 없어서, 브라우저에서 외부 소설 사이트를 직접 읽지 못하는 경우 위 프록시를 거칩니다. {url} 자리에 인코딩된 원본 주소가 들어갑니다. 리더 프록시(자동 추출) 모드는 항상 r.jina.ai를 별도로 사용하므로 이 설정과 무관합니다.

      사이트 유형 등록

      회차 URL 하나만 있으면, 어떤 숫자가 작품 ID이고 어떤 숫자가 페이지/화수인지 골라주는 것만으로 등록이 끝납니다.
      각 숫자 옆의 ID / 페이지 버튼을 눌러 역할을 지정하세요. 나머지 숫자는 그대로 고정된 값으로 취급합니다.
